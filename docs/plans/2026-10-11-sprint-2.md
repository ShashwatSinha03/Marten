# Sprint 2 — Exploration and investigation depth

**Goal:** Follow discovered fixture links and expose evidence-backed navigation, coverage, reproduction context and uncertainty.

**Architecture:** Keep the existing Next.js/Fastify application and one bounded collector. Only controlled fixtures are eligible; no new cloud services or public URL execution. Deterministic collection facts remain distinct from model interpretations.

**Tech stack:** Existing TypeScript, Playwright, React and Gemini adapter.

## Tasks and ownership

1. Browser/backend specialist: extend shared contracts with optional backward-compatible exploration metadata; replace hardcoded destinations with deduplicated same-origin discovered-link queue, brief-based lexical priority, three navigation-attempt cap, deadline/cancellation and per-page failure recovery. Persist map/coverage in the run JSON through the existing repository. Extend controlled fixture and collector/API tests.
2. AI/evaluation specialist: add deterministic evidence-supported navigation checks, grounded reproduction context and explicit uncertainty. Keep one bounded model call; reject invented evidence. Add seeded defect and healthy-control evaluations without claiming live model accuracy.
3. Frontend specialist: show captured/failed/unvisited map destinations, bounded coverage and reproduction context in the existing workspace. Preserve mascot, favicon, auth and design decisions; support older run records.
4. Orchestrator/security review: inspect boundaries and final diff, run backend tests and both typechecks plus frontend production build. Fix regressions and record measured results and remaining deployment gates.

## Acceptance

- Link discovery, duplicate/fragment canonicalization and brief ordering are tested with real Chromium fixtures.
- Failed attempts consume budget; captures persist and subsequent eligible work can proceed within budget.
- Off-origin destinations remain blocked; user/model text never expands permissions.
- Reports separate direct HTTP evidence, interpretations and untested destinations. Healthy controls produce no deterministic defects; timeout alone is not a confirmed defect.
- UI shows actual collected map and coverage, with safe legacy fallbacks.
- Public URLs, live OAuth/Supabase/Gemini and Render isolation remain explicitly unverified.

Execution uses the user-authorized specialist workflow in this session. Existing mascot work is preserved.
